# 0013 — 2D map around each terrain site (item h)

- Status: accepted
- Date: 2026-11-14

## Context

Item h of the challenge list is a 2D map. The PRD (§2c T2) asks only for "a 2D map from derived LOLA data". The LOLA
south polar grids already used for the terrain horizon (ADR 0007) cover IM-1 and IM-2 among the listed sites.

## Decision

1. **Data (`scripts/map2d.py`, `config/map2d.json`):** for every listed site inside the grids, heights on a 161 × 161
   square, 80 × 80 km, site in the centre, local north up. Cell centres are placed along great circles from the site
   (azimuthal equidistant), so a straight line from the centre is a true azimuth and the skyline distances of item j can be
   drawn on the same map. Heights use the same grids and bilinear reading as `scripts/horizon.py` (shared code). Output
   `data/map/<site>.json` (about 125 KB each, whole metres) + `data/SOURCES.json` entries. Run time under 1 s.
2. **Page (`src/map2d.js` pure, `src/map2d-ui.js`):** closed block on every card; loaded only when opened. Canvas with
   heights as a colour ramp between two CSS tokens (`--map-low`, `--map-high`) and standard relief shading with a fixed
   light from the northwest (cartographic convention; the page says it is not the real Sun). SVG overlay: site, terrain
   skyline points (item j, every 2°, inside the map), Sun and Earth direction at the chosen time (dashed when below the
   horizon), 10 km scale bar, N. Sites outside the grids and own coordinates get one line saying there is no map.
3. Shared per-card block handle `src/cardblock.js` (items h and l) instead of a second copy.

## Measured

- Centre cell height IM-2 = 5321 m, the same as the horizon profile and the elevation printed on the LROC page (ADR 0007).
  A unit test keeps centre = profile site height (± 1 m) for every terrain site.
- Smoke (Chromium 1280 / 320, WebKit iPhone 13): canvas drawn, 2 direction lines, skyline points, block fits the card.

## Consequences

- Only IM-1 and IM-2 have a map; other sites and own coordinates do not (Limitations, P3a).
- Undo: set `h_map_2d` false in `config/features.json`; delete `data/map/` and its SOURCES entries.
